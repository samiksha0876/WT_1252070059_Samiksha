# UML Class Diagram Generator — Complete

## Included functionality
- Create, select, rename, move and delete UML classes
- Click a class to open its Properties
- Add/remove/edit attributes directly from the UI
- Add/remove/edit methods directly from the UI
- Public/private/protected/package visibility notation
- Abstract class checkbox and `<<abstract>>` UML stereotype
- Inheritance/generalization relationship
- Association, aggregation, composition and dependency relationship options
- Java code generation including `abstract class` and `extends`
- Copy generated Java code
- Responsive interface

## Run
Requires Node.js 18+.

```bash
npm install
npm run dev
```

Open the Vite localhost URL.

## Important
This is a frontend-only application. It does not require a database or backend.
